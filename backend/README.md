# Backend (NestJS)

## Run commands from this folder

All npm scripts must be run from the **backend** directory:

```bash
cd backend
npm install
npm run prisma:generate   # after cloning or when schema changes
npm run build             # stop `npm run dev` first on Windows (see below)
npm run dev
```

**Windows:** If the dev server is running, `npm run build` will still complete but may warn that the Prisma generated folder could not be copied (file in use). For a full clean build, stop dev (`Ctrl+C`), then run `npm run build` again.

For production:

```bash
npm run build
npm run start
```

On **PowerShell**, if you use one line from the project root, use `;` not `&&`:

```powershell
cd backend; npm run build
cd backend; npm run dev
```

## Environment

Copy `.env.example` to `.env` and set at least:

- `DATABASE_URL` – PostgreSQL connection string (e.g. `postgresql://user:pass@localhost:5432/dsitenext`)
- `JWT_SECRET` – at least 32 characters for session signing

## Port already in use (EADDRINUSE)

If `npm run dev` fails with **address already in use 0.0.0.0:4000**:

1. **Use another port**: In `backend/.env` set `PORT=4001` (and in frontend `.env.local` set `NEXT_PUBLIC_API_URL=http://localhost:4001` if you call the API from the browser).

2. **Free ports 3000 and 4000** (from project root):
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/stop-all-dev.ps1
   ```
   Or manually for port 4000 only:
   ```powershell
   netstat -ano | findstr :4000
   taskkill /PID <pid> /F
   ```

## Body / profile upload errors

The server is configured with a 10MB body limit and a global error handler for body-parser (invalid JSON or payload too large). If you still see body-parser or profile upload errors, ensure the backend was rebuilt and restarted after the latest changes.

## Project structure & optional files

- **`src/`** – Application source (NestJS modules: auth, users, about; Prisma).
- **`src/generated/prisma`** – Prisma client output (generated by `npm run prisma:generate`). Do not edit.
- **`dist/`** – Build output (ignored by git). Created by `npm run build`.
- **`scripts/test-login.mjs`** – Optional dev script to test login against DB (no server). Safe to remove if you do not use it.
- **`scripts/`** – `build.js`, `copy-prisma.js` are required for build; `db-backup`, `seed-acp-admin`, `run-fix-admin` are operational utilities.
