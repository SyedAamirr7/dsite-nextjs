Project: dsite (Next.js frontend + NestJS backend)

This project uses Node.js and npm/yarn for dependency management. This file is only a human‑readable summary of the main requirements; actual versions are locked in the individual `package.json` files.

Environment
----------
- Node.js >= 20 (recommended)
- npm >= 10 (or Yarn/PNPM equivalent)
- PostgreSQL >= 14 (for the backend database)
